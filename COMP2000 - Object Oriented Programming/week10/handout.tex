\begin{abstract}
The goal of this week is to use the Java Streams API to process collections of objects declaratively.  Rather than writing explicit loops, you will chain operations like \texttt{filter}, \texttt{map}, \texttt{reduce}, and \texttt{collect} to express data transformations clearly and concisely.
\end{abstract}

\section*{Topics}
\begin{description}
\item[Stream pipelines] Source, intermediate operations, and terminal operations
\item[Lazy evaluation] How intermediate operations are deferred until a terminal operation is called
\item[Common operations] \texttt{filter}, \texttt{map}, \texttt{flatMap}, \texttt{sorted}, \texttt{reduce}
\item[Primitive streams] \texttt{IntStream}, \texttt{LongStream}, \texttt{DoubleStream}
\end{description}

\section*{EPIC activity}

Your task this week is to incorporate concepts from the last two weeks into your project.  Use streams and lambdas to refactor parts of your codebase.  Look for loops over collections of entities, calculations of aggregate values (sums, averages, counts), and transformations from one data shape to another.  Replace at least one explicit \texttt{for} or \texttt{while} loop with a stream pipeline.

\subsection*{Reporting}

This is a \emph{simultaneous reporting} style class.  Each team presents the loop they replaced and the stream pipeline they wrote instead.  Discuss the readability, performance, and correctness trade-offs.  Your log book should include the most interesting stream pattern you saw from another team.

\begin{teacher}
Circulate during the activity and help teams identify loops that are good candidates for stream conversion.  During reporting, encourage discussion of when streams hurt readability rather than help.
\end{teacher}

\section*{Project Guidance}

This is your team's work \emph{between classes}, do it in your own time and have it committed and pushed to your shared repository before you return next week.  Use streams to analyse your simulation state.  For example:
\begin{itemize}
\itemsep0em
\item Average energy across all herbivores: \texttt{entities.stream().filter(e -> e instanceof Herbivore).mapToDouble(Entity::energy).average()}
\item Population by species: \texttt{entities.stream().collect(Collectors.groupingBy(Entity::species, Collectors.counting()))}
\item Entities below starvation threshold: \texttt{entities.stream().filter(e -> e.energy() < THRESHOLD).toList()}
\end{itemize}

Find one explicit loop over entities in your code and replace it with a stream pipeline.  Commit both versions so you can compare them.  Record what you did in your log book.  Anything you add beyond the class activity is the kind of contribution the Uniqueness and Creativity rubric rewards.

\section*{Self Study Exercises}
\begin{enumerate}
\item What is a stream?  How is it different from a collection?

\item What are the three stages of a stream pipeline?  Give a concrete example.

\item What does it mean that streams are lazily evaluated?  Why does this matter for performance?

\item Given a \texttt{List<String>}, write a stream pipeline that converts each string to uppercase, filters those longer than 4 characters, sorts them, and collects them into a new list.

\item What is \texttt{flatMap}?  Write an example that flattens a \texttt{List<List<Integer>>} into a single \texttt{List<Integer>}.

\item Given a \texttt{List<Person>} with \texttt{getName()} and \texttt{getAge()}, use streams to compute the average age of people older than 18.

\item Use \texttt{reduce} to compute the product of all integers in a \texttt{List<Integer>}.  What value does it return if the list is empty?

\item What is the difference between \texttt{map} and \texttt{flatMap}?  When would you choose one over the other?

\item Write a stream pipeline that takes a \texttt{List<Transaction>} (with \texttt{getCurrency()} and \texttt{getAmount()}) and returns a \texttt{Map<String, List<Transaction>>} grouping transactions by currency.

\item What are primitive streams (\texttt{IntStream}, \texttt{LongStream}, \texttt{DoubleStream})?  Why do they exist?  Give an example using \texttt{IntStream.range}.
\end{enumerate}
